API de Tarefas com NestJS + Prisma + MySQL

Do zero ao CRUD funcionando — passo a passo

SENAI · Técnico em Desenvolvimento de Sistemas

Use as setas ← → do teclado para navegar

O que vamos construir

  • Uma API REST para cadastro de tarefas
  • Criar, listar, buscar, atualizar e remover (CRUD)
  • Dados salvos em um banco MySQL
  • Acesso ao banco via ORM (Prisma), sem escrever SQL à mão
Cliente (HTTP) → Controller → Service → Prisma → MySQL

O que é ORM?

Object-Relational Mapping: mapeia tabelas do banco para objetos do código.

Sem ORM (SQL)Com Prisma
SELECT * FROM Tarefa;prisma.tarefa.findMany()
INSERT INTO Tarefa (titulo) VALUES ('x');prisma.tarefa.create({ data: { titulo: 'x' } })

Vantagens: menos SQL manual, tipagem TypeScript, migrações versionadas.

Pré-requisitos

  • Node.js 22 LTS ou superior (node -v)
  • npm 10 ou superior (npm -v)
  • Docker (para subir o MySQL sem instalar nada) (docker -v)
  • Um editor (VS Code) e um cliente HTTP (curl, Insomnia ou Postman)

Passo 6 — Criar a tabela (migração)

npx prisma migrate dev --name criar-tarefas

Sempre que alterar o schema.prisma, rode esses comandos de novo.

Passo 7 — PrismaService

Uma classe do Nest que conecta ao banco e pode ser injetada em qualquer lugar.

src/prisma/prisma.service.ts

import { Injectable, OnModuleInit } from '@nestjs/common';
import { PrismaMariaDb } from '@prisma/adapter-mariadb';
import { PrismaClient } from '../generated/prisma/client.js';

@Injectable()
export class PrismaService extends PrismaClient implements OnModuleInit {
  constructor() {
    const adapter = new PrismaMariaDb(process.env.DATABASE_URL!);
    super({ adapter });
  }

  async onModuleInit() {
    await this.$connect();
  }
}

Passo 8 — PrismaModule

src/prisma/prisma.module.ts

Passo 11 — Service

src/tarefas/tarefas.service.ts

@Injectable()
export class TarefasService {
  constructor(private readonly prisma: PrismaService) {}

  criar(dto: CriarTarefaDto) {
    return this.prisma.tarefa.create({ data: { titulo: dto.titulo } });
  }

  listar() {
    return this.prisma.tarefa.findMany({ orderBy: { id: 'asc' } });
  }

  async buscar(id: number) {
    const tarefa = await this.prisma.tarefa.findUnique({ where: { id } });
    if (!tarefa) throw new NotFoundException(`Tarefa ${id} não encontrada`);
    return tarefa;
  }

  async atualizar(id: number, dto: AtualizarTarefaDto) {
    await this.buscar(id);
    return this.prisma.tarefa.update({ where: { id }, data: dto });
  }

  async remover(id: number) {
    await this.buscar(id);
    return this.prisma.tarefa.delete({ where: { id } });
  }
}

Passo 12 — Controller

src/tarefas/tarefas.controller.ts

@Controller('tarefas')
export class TarefasController {
  constructor(private readonly tarefasService: TarefasService) {}

  @Post()
  criar(@Body() dto: CriarTarefaDto) { return this.tarefasService.criar(dto); }

  @Get()
  listar() { return this.tarefasService.listar(); }

  @Get(':id')
  buscar(@Param('id', ParseIntPipe) id: number) { return this.tarefasService.buscar(id); }

  @Patch(':id')
  atualizar(@Param('id', ParseIntPipe) id: number, @Body() dto: AtualizarTarefaDto) {
    return this.tarefasService.atualizar(id, dto);
  }

  @Delete(':id')
  remover(@Param('id', ParseIntPipe) id: number) { return this.tarefasService.remover(id); }
}

Desafio 2 — Filtrar tarefas por situação

Rota: GET /tarefas?concluida=true (ou false). Sem o parâmetro, lista todas.

src/tarefas/tarefas.controller.ts

@Get()
listar(
  @Query('concluida', new ParseBoolPipe({ optional: true }))
  concluida?: boolean,
) {
  return this.tarefasService.listar(concluida);
}

src/tarefas/tarefas.service.ts

listar(concluida?: boolean) {
  return this.prisma.tarefa.findMany({
    where: concluida === undefined ? {} : { concluida },
    orderBy: { id: 'asc' },
  });
}

ParseBoolPipe converte o texto "true" da URL em booleano e recusa valores inválidos (400).

Desafio 3 — Validar o título com class-validator

npm install class-validator class-transformer

src/main.ts

app.useGlobalPipes(new ValidationPipe({ whitelist: true }));

src/tarefas/dto/criar-tarefa.dto.ts

import { IsNotEmpty, IsString, MaxLength } from 'class-validator';

export class CriarTarefaDto {
  @IsString({ message: 'O título deve ser um texto' })
  @IsNotEmpty({ message: 'O título é obrigatório' })
  @MaxLength(191, { message: 'O título deve ter no máximo 191 caracteres' })
  titulo: string;
}

whitelist: true descarta campos que não estão no DTO.

Comparando: class-validator × Zod

class-validatorZod
EstiloClasse + decoratorsSchema (objeto)
Tipo TypeScriptEscrito à mão na classeGerado: z.infer
Integração com NestNativa (ValidationPipe)Pipe próprio (poucas linhas)
Reuso no front-endDifícilFácil (mesmo schema)

Zod — schema + tipo

import { z } from 'zod';

export const criarTarefaSchema = z.object({
  titulo: z.string().min(1, 'O título é obrigatório').max(191),
});

export type CriarTarefaDto = z.infer<typeof criarTarefaSchema>;

Zod — pipe e uso no controller

@Injectable()
export class ZodPipe implements PipeTransform {
  constructor(private schema: ZodType) {}
  transform(value: unknown) {
    const r = this.schema.safeParse(value);
    if (!r.success) throw new BadRequestException(r.error.issues);
    return r.data;
  }
}

@Post()
criar(@Body(new ZodPipe(criarTarefaSchema)) dto: CriarTarefaDto) { ... }

Neste curso usamos class-validator por ser o padrão do Nest; o Zod é muito visto no mercado.
